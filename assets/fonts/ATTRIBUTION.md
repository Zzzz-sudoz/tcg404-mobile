# Barlow Condensed

Designed by Jeremy Tribby. Distributed under the SIL Open Font License in `OFL.txt`.

These locally stored weights are used for the collector storefront's condensed display typography. No remote font request is made by the app.

- `barlow-2.ttf`: weight 800, https://fonts.gstatic.com/s/barlowcondensed/v13/HTxwL3I-JCGChYJ8VI-L6OO_au7B47b1_3E.ttf
